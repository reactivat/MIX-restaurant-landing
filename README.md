# MIX

Лендинг кафе на HTML, CSS и JavaScript. Был разработан в качестве курсовой работы в самом начале пару лет назад, а теперь с учетом опыта и возможностей приведен к более приятному и качественному виду.

Здесь есть меню с выбором блюда, галерея интерьера, отзывы и контакты. Вёрстка адаптирована под телефон и компьютер.

Форма считает стоимость блюд и позволяет скачать заявку в текстовом файле. Отправки в кафе нет — данные остаются в браузере. Адрес и цены демонстрационные.

Чтобы посмотреть сайт, достаточно открыть `index.html`. Установка и сборка не нужны.

Для локальной проверки через HTTP: `node scripts/serve.mjs`, затем открыть `http://127.0.0.1:8768`.

Фото имеют несколько размеров WebP; браузер выбирает вариант по экрану и плотности пикселей. Скрытые слайды, фон между секциями и дополнительные скрипты подгружаются по мере необходимости. Карта загружается автоматически за 600 пикселей до появления блока контактов.

Шрифт — Inter. Часть изображений сгенерирована. Значки YouTube и VK взяты из [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0-1.0), RUTUBE и MAX — из [брендбука RUTUBE](https://rutube.ru/brand/) и [брендбука MAX](https://go.max.ru/brandbook/).
